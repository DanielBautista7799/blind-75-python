## Problem Summary

Given a sorted array that has been rotated, find the minimum value in the array.

The values in the array are unique.

## Inputs and Expected Output

- Input: a rotated sorted list of integers.
- Output: the smallest integer in the list.

## Edge Cases to Consider

- The array was not rotated.
- The minimum is at the beginning.
- The minimum is at the end.
- The array only has one value.
- The array has two values.
