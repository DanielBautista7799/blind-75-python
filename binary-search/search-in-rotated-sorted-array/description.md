## Problem Summary

Given a sorted array that has been rotated, find the index of a target value.

If the target is not in the array, return `-1`.

## Inputs and Expected Output

- Input: a rotated sorted list of integers and a target integer.
- Output: the index of the target, or `-1` if it does not exist.

## Edge Cases to Consider

- The target is in the left sorted half.
- The target is in the right sorted half.
- The target is not in the array.
- The array was not rotated.
- The array only has one value.
- The target is at the first or last index.
