## Problem Summary

Given the head of a linked list, return `True` if the list contains a cycle and `False` otherwise.

## Inputs and Expected Output

- **Input:** The head of a singly linked list.
- **Output:** `True` if following `next` pointers eventually reaches a node that was already visited. Otherwise `False`.

## Edge Cases to Consider

- Empty linked list.
- One node with no cycle.
- One node pointing to itself.
- Cycle starting at the head.
- Cycle starting somewhere in the middle of the list.
