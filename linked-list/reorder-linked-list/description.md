## Problem Summary

Given the head of a singly linked list, reorder the nodes so they alternate between the front and back of the original list.

## Inputs and Expected Output

- **Input:** The head of a singly linked list.
- **Output:** The same linked list reordered in place as first node, last node, second node, second-to-last node, and so on.

## Edge Cases to Consider

- One node.
- Two nodes.
- An odd number of nodes.
- An even number of nodes.
- Making sure the reordered list ends correctly without creating a cycle.
