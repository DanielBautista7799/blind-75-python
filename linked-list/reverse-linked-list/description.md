## Problem Summary

Given the head of a singly linked list, reverse the direction of every link and return the new head of the list.

## Inputs and Expected Output

- Input: the head node of a singly linked list.
- Output: the new head after the linked list has been reversed.

## Edge Cases to Consider

- Empty linked list.
- One node.
- Two nodes.
- Multiple nodes.
- Making sure the old head points to `None` after reversing.
