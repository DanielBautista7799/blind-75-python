## Problem Summary

Given a string containing only brackets, determine whether every opening bracket has a matching closing bracket in the correct order.

## Inputs and Expected Output

- Input: a string containing only `()`, `{}`, and `[]`.
- Output: `True` if the brackets are valid, otherwise `False`.

## Edge Cases to Consider

- Empty string.
- Only opening brackets.
- Only closing brackets.
- Nested brackets.
- Incorrect order.
- Leftover opening brackets.
